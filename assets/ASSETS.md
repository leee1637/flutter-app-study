# Куда положить свои картинки

## Фото товаров

Фото товаров **не кладут в assets** — выбираются в приложении:
**Добавить товар → Галерея** или **Камера**. Файл сохраняется на телефоне автоматически.

---

## 1. Фон на экране входа и регистрации (главное)

**Файл:** `assets/images/auth_background.png`

Полный путь на диске:
```
c:\Users\PC1\Desktop\flutter_app\assets\images\auth_background.png
```

| Параметр | Значение |
|----------|----------|
| Имя файла | строго `auth_background.png` |
| Размер | 1080×1920 px (вертикальное фото) |
| Формат | PNG или JPG (если JPG — переименуйте в `.png` или смените константу в коде) |

После копирования файла в папку:
```bash
flutter pub get
```
Затем полностью перезапустите приложение (Stop → Run), не только hot reload.

Если файла нет — будет синий/цветной фон (это нормально).

---

## 2. Заставка при запуске приложения

**Файл:** `android/app/src/main/res/drawable/splash_image.png`

1. Удалите `splash_image.xml` в той же папке (если есть).
2. Положите своё изображение `splash_image.png` (1080×1920).

---

## 3. Иконка на рабочем столе телефона

**Файл:** `assets/icon/icon.png` (1024×1024)

Затем в терминале:
```bash
dart run flutter_launcher_icons
flutter run
```

---

## Быстрая проверка

В папке `assets/images/` должен лежать ваш файл:
```
flutter_app/
  assets/
    images/
      auth_background.png   ← ваше фото
```
